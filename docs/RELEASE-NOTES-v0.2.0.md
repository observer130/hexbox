# hexbox v0.2.0

功能版：相位变化不再等 2 秒、标签能悬停看详情、掉线重连会自动恢复。

## 新增

- **LCU 事件订阅**：相位一变立刻跟上（原来最坏等 2 秒）。2 秒轮询保留兜底，判定逻辑一行没改。
- **标签悬停提示**：鼠标停在标签上看详情（统计日期 / 来源 / 选取率）。画布仍然穿透，点击照旧落到游戏。
- **重连恢复**：客户端重启型断线回到对局后，自动重置"本局不重试"并补回英雄身份（只恢复一次）。
- **自测三个场景**：`HEXBOX_LABEL_OVERLAY_TEST=1` 会自己跑悬停 / 清空无残留 / 改尺寸跟随，失败即非零退出码。

## 验证

- 三局真实会话闭环回放：两局逐项一致；第三局只有已知的 ±3 帧库格点差（A/B 复核过，与本次改动无关）。
- 单测 877 → 982；`typecheck` / `test` / `build` 全绿。

## 已知问题

- 读不到 LCU 凭证时（WeGame 版 lockfile 为 0 字节、非管理员）事件订阅不生效，退化为 2 秒轮询。
- 重连路径还没在真机验到（录制里没出现过 `Reconnect`），纯判定有单测覆盖。
- 便携版不支持自助更新；数据是快照，更新数据要重新发包。

日志：`%LOCALAPPDATA%\hexbox\logs\overlay.log`。退出请用**托盘 → 退出**（点窗口 X 只是隐藏）。
