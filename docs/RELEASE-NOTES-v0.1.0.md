# hexbox v0.1.0

**hexbox** 是英雄联盟国服「海克斯乱斗 / 极限闪击轮换模式」的辅助工具（Windows 桌面常驻程序）。
本版是**第一个可分发版本**。

## 这是什么

- **选人阶段**：在英雄卡片上叠加该英雄在乱斗模式下的**胜率标签**（官方榜单数据）。
- **局内**：在海克斯（强化符文）卡片上叠加 **S / A / B / C 强度标签**与**选取率**
  （来自官方「该英雄」的强度表；OCR 识别屏幕上的官方 UI，读不到或官方表里没有该海克斯时**不画任何字母**，绝不猜）。
- **托盘常驻**：程序没有可见主窗口，交互全部在**系统托盘**里。
- 不读游戏内存、不注入、不解析网络包：只用官方公开数据面 + LCU 本地 REST API + 屏幕截图识别。

## 安装

1. 下载并运行 **`hexbox-setup-0.1.0-x64.exe`**（NSIS 安装包，中文向导，可选安装目录）。
   **安装本身不需要管理员权限**（每用户安装）。
2. 安装完成后从开始菜单/桌面快捷方式启动。

> ⚠️ **程序运行时需要管理员权限（会弹 UAC）**，这是刻意的、也是必需的：
> hexbox 要读取英雄联盟客户端的 LCU 凭证（国服 WeGame 环境下只有管理员能读到），
> 而选人/局内两块标签都以 LCU 阶段为准。
> **如果以非管理员身份运行，程序不会报错，但两块标签都不会出现**——
> 看起来像"装了没用"，实际是权限不足。**请务必允许 UAC 提权**。
>
> 取消方式没有意义：把 `requestedExecutionLevel` 改成 `asInvoker` 能免掉弹窗，
> 但在国服下选人/局内标签会**全部不可用**。

**系统要求**：Windows 10 / 11（x64）、英雄联盟国服客户端（WeGame）。

## SmartScreen 提示（本版未做代码签名）

本程序**没有购买代码签名证书**，产物是**未签名**的，所以 Windows 可能弹出
**「Windows 已保护你的电脑 / 未知发布者」**：

> 点「**更多信息**」→「**仍要运行**」即可。

这是"没有数字证书"的正常表现，不是病毒。
可随时自行校验：文件属性 → 「数字签名」页应为**空**；以及下面的 SHA256。
若你的电脑由公司统一管理（AppLocker / WDAC / 组策略只允许已签名程序），本程序**可能无法安装**，这不是能靠文档绕过的。

## 托盘（唯一的交互入口）

右键任务栏托盘里的 hexbox 图标，菜单**只有四项**：

| 菜单项 | 可点 | 说明 |
|---|---|---|
| `状态：选人中 / 局内 / 等待客户端 …` | 否 | 当前阶段 |
| `数据更新时间：2026-10-05（统计日期）` | 否 | 内置数据快照的官方统计日期 |
| `检查更新` | **是** | 手动检查是否有新版本（**只在点击时联网**，不后台轮询） |
| `退出` | **是** | 唯一真正的退出方式 |

> ⚠️ **点窗口的 X（关闭）不会退出程序**——它只是把窗口隐藏到托盘，
> 程序继续在后台常驻。**要退出请右键托盘图标 → 退出。**
>
> Windows 11 默认把新出现的托盘图标收进 `^`（向上的小箭头）隐藏区里，
> 找不到图标时请先点 `^`，或把它拖到任务栏上常驻。

## 日志与数据

- **日志**：`%LOCALAPPDATA%\hexbox\logs\overlay.log`
  （超过 4 MB 自动轮转为 `overlay.log.1`；启动时日志第一行会打印它的**绝对路径**）。
- **数据目录**：`%LOCALAPPDATA%\hexbox\data\`（可选；放进去的 5 个 json 会覆盖安装目录里的快照）。
- **更新下载的安装包**：`%TEMP%\hexbox-update\`。

因为打包后是 GUI 子系统进程（没有控制台），出问题**只有日志文件**能看，所以排查请先看上面这个文件。

## 已知问题与限制（如实）

1. **便携版不支持自助更新**：`检查更新` 下载并启动的永远是 **NSIS 安装包**，
   点了会把它装成正式安装版。想继续用便携版，请手动下载新的 `hexbox-portable-*.exe`。
2. **国内访问 GitHub 可能很慢或不通**：检查更新的查版本超时是 15 s、下载超时 30 min；
   失败弹窗里会给出「打开下载页」按钮，可手动下载。
3. **数据是快照，不会自己更新**：内置的是打包当天的官方榜单/强度表（菜单第 2 项能看到统计日期）。
   **更新数据需要重新发包**；不想等新版本的话，可自行把最新的 5 个 json 放进
   `%LOCALAPPDATA%\hexbox\data\`（见上）。
4. **没有任何代码签名**：见上面的 SmartScreen 一节；企业管控环境可能直接拦截。
5. **每次启动都会弹 UAC**：Windows 不允许对程序记住"总是放行"。
   若要做开机自启，请用「任务计划程序」（勾选"以最高权限运行"），
   普通"启动"文件夹里的快捷方式每次都会弹窗。
6. **强度表只覆盖官方公布过的那部分海克斯**：官方每英雄的强度表只有 95~162 行，
   卡片上的海克斯若不在该英雄的官方表里（或 OCR 无法确认），**不会画任何字母**。
   局内显示的口径始终是"**官方统计里这个英雄拿这个海克斯的数据**"，数字是**选取率**，不是胜率。
7. **首次启动"什么都看不到"是正常的**：没有客户端、或不在选人/对局阶段时，屏幕上不会出现任何东西，
   程序只是一个托盘常驻进程——请先看托盘状态项与日志。

## 反馈

问题请附上 `%LOCALAPPDATA%\hexbox\logs\overlay.log`（里面不含账号令牌，但**请自行过目**后再贴）。
