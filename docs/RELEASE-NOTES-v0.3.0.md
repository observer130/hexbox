# hexbox v0.3.0

数据版：数据不再跟安装包走，启动后自动检查、自动后台更新。

## 变更

- **数据与安装包解耦**：数据放 `文档\hexbox\data`（OneDrive 重定向时自动跟随）。
  安装包不再内置 6.26 MB 数据，只留 0.24 MB 的海克斯名字指纹库
  （构建期从字体生成，运行时无法重建）。
- **启动全自动**：首次运行自动后台下载；之后启动时每天最多检查一次官方统计日期，
  有新数据自动后台下载。成功/失败只弹托盘气泡，不弹确认框、不打断游戏。
- **托盘文案**：第二行由 `数据更新时间：…（统计日期）` 改为 `统计日期：2026-11-01`；
  没有官方日期时显示 `文件时间：…`，两种口径不混用。
- **升级无感**：旧 `%LOCALAPPDATA%\hexbox\data` 与旧安装包的 `resources\data`
  仍可读；下一次更新自动写到文档目录。
- **手动入口保留**：托盘「更新数据」可立即触发/重试，运行中再点同一项 = 取消；
  失败/取消都保留现有数据。
- 同步引擎与 `pnpm sync` 同一份（`runDataSync`）：原子写、空数据不覆盖、
  取消走 `AbortSignal`。

## 验证

- 真实上游同步：CommunityDragon 594 海克斯 / 254 英雄；腾讯图鉴 235；
  榜单 214 / 173（官方统计日期 2026-11-01）。
- 单测 982 → 1034；`pnpm typecheck` / `pnpm test` / `pnpm build` 全绿。
- 覆盖层 UI 未在 CI 里点过（无桌面）；首次下载与托盘按真机流程手动验证。

## 已知问题

- 首次运行必须联网一次（约 6–10 MB，几分钟）；断网会失败，可稍后从托盘手动重试。
- 上游改版导致同步失败时保留旧数据，不影响使用。
- 便携版不支持自助更新（与以前相同）。
- 数据放在 OneDrive 同步的文档目录时，首次下载会让 OneDrive 上传约 6 MB（正常）。
