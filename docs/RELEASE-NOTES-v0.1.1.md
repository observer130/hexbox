# hexbox v0.1.1

**热修复版**：修掉 0.1.0 真机上最影响使用的三个问题（局内海克斯面板"开了却一个标签都不画"、
选人阶段把标签画到**队友**的顶栏上、选人第一阶段卡片检出不稳定/画错位置），
并按真机标定重做了选人候选卡的几何。

> 0.1.0 是第一个可分发版本；本版**只修问题**，界面与交互（托盘四项菜单、日志位置、
> 数据快照口径）与 0.1.0 完全一致。

## 这一版修了什么

### 1. 局内海克斯面板已经弹出，却一个强度标签都不画

真机日志（0.1.0）：面板在屏 **25.7 秒**，门控在 1/3 分辨率上判"面板在"，
但**原生 1:1 重检**量到"卡片内部 40 ≥ 阈值 40"判"不在" →
开边沿那一整批识别直接作废，而且**只识别一次、没有第二次**。

- 原生重检失败时，退回**门控刚验过的矩形**继续识别（矩形是归一化的，两个分辨率通用）；
- 识别失败后在有界预算内重试（最多 3 次、间隔 ≥400ms、开边沿后 5 秒内，且只在稳定帧上）；
- 修完之后：同一块面板不会再出现"整块面板零标签"。

### 2. 选人阶段给**队友**画标签 / 我的三选一标签一闪就没

真机日志（0.1.0，同一局选人段）：

```text
第二阶段(picking): 顶栏占用 1 格 … 3 格 … 10 格      ← 我还在三选一，却连画 5 轮队友标签
第二阶段(locked):  顶栏占用 10 格 …                  ← 我自己锁了之后才应该是 locked
```

旧判据 `isPhase2 = 顶栏占用 > 0 || locked`：队友先锁完就把顶栏填满，
于是生产者从"我的三张卡"被抢到"顶栏"，我的卡片标签消失、换成队友的 →
下一轮又切回来 → 标签记忆被反复清空（用户看到的"准确率非常低"）。

- 现在**只认我自己那条 pick 动作是否完成**（LCU 选人会话）：
  `locked` → 顶栏；`picking` → 我的卡片（顶栏占用是队友的，不作依据）；
  找不到我的 pick 动作 → `unknown`（**不再默认成 picking**），才用顶栏占用兜底；
- `第二阶段(picking)` 这行日志在代码里已经**不可达**（有单测锁住这条不变量）。

### 3. 选人第一阶段"候选卡"几何重新标定（真机实测）

旧 `detectCards` 在同一套「选择你的英雄」界面上会在 **0 张 / 2 张 / 3 张**之间抖动
（根因：按卡宽 ±2% 聚桶，而选人卡左右边框的测量差 1.2%~2.3% 就跨桶了），
并且在**锁定后的大立绘**帧上会给出两个位置完全错误的矩形（把胜率画到屏幕中间）。

- 新增 `vision/champ-select-cards.ts`：真机标定出的**居中一行、2 或 3 张**布局
  （卡宽 0.1459、卡高 0.4167、上缘 0.2484、中心距 0.1686，窗口归一化），
  判据是**四条边框的"亮线 vs 卡外背景"亮度差**（实测正样本单边 ≥16.2、四边和 ≥156，
  阴性 ≤8）；
- **不用**"卡内暗"这条判据：候选卡里是英雄立绘（亮卡），实测卡内平均亮度与
  第二阶段整屏立绘重叠（48.7~73.3 vs 39.7~117.9）；
- 逐帧复验（6 帧真机正样本 / 13 帧阴性）：**正样本 6/6 检出、阴性 13/13 零误检**，
  与目视真值偏差 ≤5 DIP；OCR 出的英雄名与目视一致 10/12；
- 开关 `HEXBOX_CHAMP_SELECT_CARDS`：`geometry`（默认）/ `legacy`（旧检出器，对照）/
  `off`（一张都不画，只出顶栏标签）。**几何失败不会退回旧检出器** —— 宁可不画，绝不画错位置。

### 4. 第 2 次（7 级）海克斯 offer 有时整局抓不到

旧逻辑只在**死亡**时开截屏窗口。真机记录里出现过：7 级 offer 连续**三个**死亡窗口
（每个 45 秒）都没见到面板、15 级 offer 五个窗口全空 —— 面板可能在死亡窗口之外
出现/被选掉。

- 新增**升级定向开窗**：当等级升到某个**仍未选**的待选等级（默认集合 0/7/11/15）时，
  立刻开一次窗口看一眼；平时（没有未选 offer / 升级没跨待选等级）依然**零取帧**；
- 窗口超时自愈：没见到面板就关掉，**不消耗**待选（下次死亡/升级再试）；
- 这一条是**有代价的改动**（升级那一刻可能白开一个 ≤45s 的窗口），
  证据与"面板到底在什么时候出现"的讨论见 `docs/AUGMENT-PANEL.md` 与提交说明。

### 5. 诊断（不改变行为，排错用）

- 每条日志带 **`[+秒]`** 偏移，跨进程拼接日志时能直接看时序；
- 每次关窗打一行 **`采样 N 帧 / 命中 H / 托底 P / 裁决`**（"为什么判成关"不再靠猜）；
- `HEXBOX_AUGMENT_API_TRACE=1`：逐次打印 2999 采样（等级/死亡/待选/开窗状态）；
- `HEXBOX_AUGMENT_PENDING_PROBE_MS`：待选期间的低频探针，**默认 0 = 严格零取帧**（用户裁决）。

## 安装

1. 下载并运行 **`hexbox-setup-0.1.1-x64.exe`**（NSIS 安装包，中文向导，可选安装目录）。
   **安装本身不需要管理员权限**（每用户安装）。已装 0.1.0 的机器直接覆盖安装即可。
2. 安装完成后从开始菜单/桌面快捷方式启动。

> ⚠️ **程序运行时需要管理员权限（会弹 UAC）**，这是刻意的、也是必需的：
> hexbox 要读取英雄联盟客户端的 LCU 凭证（国服 WeGame 环境下只有管理员能读到），
> 而选人/局内两块标签都以 LCU 阶段为准。
> **如果以非管理员身份运行，程序不会报错，但两块标签都不会出现**——
> 看起来像"装了没用"，实际是权限不足。**请务必允许 UAC 提权**。

**系统要求**：Windows 10 / 11（x64）、英雄联盟国服客户端（WeGame）。

## 托盘（唯一的交互入口）

右键任务栏托盘里的 hexbox 图标，菜单**只有四项**（与 0.1.0 相同）：

| 菜单项 | 可点 | 说明 |
|---|---|---|
| `状态：选人中 / 局内 / 等待客户端 …` | 否 | 当前阶段 |
| `数据更新时间：2026-10-05（统计日期）` | 否 | 内置数据快照的官方统计日期 |
| `检查更新` | **是** | 手动检查是否有新版本（**只在点击时联网**，不后台轮询） |
| `退出` | **是** | 唯一真正的退出方式 |

> ⚠️ **点窗口的 X（关闭）不会退出程序**——它只是把窗口隐藏到托盘。
> **要退出请右键托盘图标 → 退出。**
>
> Windows 11 默认把新出现的托盘图标收进 `^`（向上的小箭头）隐藏区里，
> 找不到图标时请先点 `^`，或把它拖到任务栏上常驻。

## 日志与数据

- **日志**：`%LOCALAPPDATA%\hexbox\logs\overlay.log`
  （超过 4 MB 自动轮转为 `overlay.log.1`；启动时日志第一行会打印它的**绝对路径**）。
- **数据目录**：`%LOCALAPPDATA%\hexbox\data\`（可选；放进去的 5 个 json 会覆盖安装目录里的快照）。
- **更新下载的安装包**：`%TEMP%\hexbox-update\`。

打包后是 GUI 子系统进程（没有控制台），出问题**只有日志文件**能看，所以排查请先看上面这个文件。

## 已知问题与限制（如实）

1. **便携版不支持自助更新**：`检查更新` 下载并启动的永远是 **NSIS 安装包**，
   点了会把它装成正式安装版。想继续用便携版，请手动下载新的 `hexbox-portable-*.exe`。
2. **国内访问 GitHub 可能很慢或不通**：检查更新的查版本超时是 15 s、下载超时 30 min；
   失败弹窗里会给出「打开下载页」按钮，可手动下载。
3. **数据是快照，不会自己更新**：内置的是打包当天的官方榜单/强度表（菜单第 2 项能看到统计日期）。
   **更新数据需要重新发包**；不想等新版本的话，可自行把最新的 5 个 json 放进
   `%LOCALAPPDATA%\hexbox\data\`（见上）。
4. **没有任何代码签名**：见上面的 SmartScreen 一节；企业管控环境可能直接拦截。
5. **每次启动都会弹 UAC**：Windows 不允许对程序记住"总是放行"。
   若要做开机自启，请用「任务计划程序」（勾选"以最高权限运行"）。
6. **强度表只覆盖官方公布过的那部分海克斯**：官方每英雄的强度表只有 95~162 行，
   卡片上的海克斯若不在该英雄的官方表里（或 OCR 无法确认），**不会画任何字母**。
   局内显示的口径始终是"**官方统计里这个英雄拿这个海克斯的数据**"，数字是**选取率**，不是胜率。
7. **首次启动"什么都看不到"是正常的**：没有客户端、或不在选人/对局阶段时，屏幕上不会出现任何东西，
   程序只是一个托盘常驻进程——请先看托盘状态项与日志。
8. **选人卡片几何只覆盖 2 张与 3 张两种排布**（真机实测到的就是这两种）。
   若某次排布与标定不符，程序会**一张卡片标签都不画**（不会画到错位置）；
   用 `HEXBOX_CHAMP_SELECT_CARDS=legacy` 可退回旧检出器对照。
9. **选人卡片上的英雄名识别偶尔会漏**（真机 12 张卡实测 10 张认出）：
   名字指纹匹配的得分就在阈值附近，认不出时**不画**那个标签（不会画错英雄）。

## 反馈

问题请附上 `%LOCALAPPDATA%\hexbox\logs\overlay.log`（里面不含账号令牌，但**请自行过目**后再贴）。
